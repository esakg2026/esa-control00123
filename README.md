# ESA Control

Система контроля бухгалтерского аутсорсинга. Создатель: Эркебаев Самат Адылович, компания ESA.
Вопросы и поддержка: Telegram https://t.me/ESAControl, тел. +79055140226

Это установленное веб-приложение (PWA) с **онлайн-базой данных на Supabase**: все сотрудники работают с одной базой со своих устройств, а права ролей проверяет сервер.

## Файлы
- `index.html` — всё приложение (один файл)
- `manifest.webmanifest`, `sw.js`, `icons/` — установка как приложения и работа без сети для самой программы
- `404.html`, `_redirects`, `.gitignore` — служебные
- `supabase/README.md` — устройство базы данных

## Публикация: GitHub → Netlify (автообновление)
1. Создайте на github.com пустой репозиторий `esa-control`.
2. В папке проекта выполните:
   ```
   git init -b main
   git add .
   git commit -m "ESA Control"
   git remote add origin https://github.com/ВАШ-ЛОГИН/esa-control.git
   git push -u origin main
   ```
3. Netlify → Add new site → Import an existing project → GitHub → выберите репозиторий. Build command пусто, Publish directory `.` → Deploy.
   (Или GitHub Pages: Settings → Pages → Deploy from a branch → main / root.)
4. Каждое следующее `git push` обновляет сайт сам.

## Первый вход
Логин `ESA`, пароль выдан владельцу. **Сразу смените пароль**: значок ключа вверху справа.

## Как это работает
- Администратор ESA создаёт кабинеты клиентов: раздел «Доступы клиентов ESA».
- Владелец фирмы создаёт сотрудников с логином и паролем: раздел «Сотрудники». Сотрудник входит со своего телефона или компьютера и видит только свои задания и клиентов.
- Все изменения сохраняются на сервере и появляются у остальных за несколько секунд.
- Excel: Настройки → «Данные» → «Excel (.xlsx)».

## Важно про бесплатный тариф Supabase
Бесплатный проект Supabase приостанавливается после недели без обращений. Если сайт перестал входить: откройте supabase.com/dashboard и нажмите Restore project (данные сохраняются). Для постоянной работы клиентов переведите проект на платный тариф Pro.
