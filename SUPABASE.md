# База данных (Supabase, проект esa-control)

Регион: eu-central-1. Адрес: https://kmivexilyceenpctwpva.supabase.co

## Устройство
- Таблицы лежат в закрытой схеме `esa` (firms, members, sessions, entities). Прямого доступа с сайта к ним нет.
- Сайт вызывает только функции `public.*` через публичный (anon) ключ. Каждая функция сама проверяет токен сессии и права роли.
- Пароли хранятся как bcrypt, токены сессий как SHA-256. Вход блокируется на 10 минут после 5 неверных паролей.
- Данные хранятся как сущности (`entities`): c = клиент, t = задача, e = сотрудник, l = журнал, g = настройки, a = аудит.

## Права
- owner (владелец фирмы): читает и пишет всё в своей фирме.
- chief (главбух): видит свои задачи и задачи своих клиентов, может менять и делегировать их.
- acc (бухгалтер): видит только свои задачи; может менять статус, время, комментарий; не может переназначать и закрывать (кроме вопросов аудита).
- Администратор платформы (фирма ESA): создаёт, отключает и удаляет кабинеты клиентов.

## Функции API
app_login, app_me, app_logout, pass_change, sync_pull, sync_get, sync_push,
member_create, member_set, member_delete, member_pass,
plat_list, plat_firm_create, plat_set, plat_delete, plat_reset.

Публичный ключ в `index.html` предназначен для открытого использования: безопасность держится на проверках внутри функций, а не на секретности ключа.
Секретный ключ service_role в сайт НЕ вставляйте никогда.
